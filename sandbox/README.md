# サンドボックス（動作確認用のシナリオと共有パック）

SRC#Site の機能を本番で一通り確かめるための、シナリオ 1 本と共有パック 1 つ。

> **生成AIで作ったテスト用のものです。** 文章・データ・マップ・画像・音楽・効果音は、すべて生成AI（Claude）が作りました。画像は単純な図形（顔の絵には「TEST」と入れてある）、音楽と効果音は単純な音の並びで、作品として遊ぶ・素材として使うためのものではありません。サイトに載せるときも、題名と説明の最初でそのことが分かるようにする（下の「サイトに入れる文」）。

## 作る

```sh
python3 -I scripts/make-sandbox.py            # out/sandbox/ に 2 つの zip を作る
```

| zip | 中身 |
|---|---|
| `sandbox-scenario.zip` | シナリオ「サンドボックス」（`sandbox/scenario/`。マップはスクリプトが作る）。画像・音は入っていない |
| `sandbox-pack.zip` | 共有パック「サンドボックス素材」の投稿（`sandbox/pack/README.txt` と、スクリプトが作る画像・MIDI・WAV） |

同じ入力からは同じ zip ができる（日時を固定している）。

## 確かめられること

| 機能 | 確かめ方 |
|---|---|
| パックを作る・投稿・承認・zip への反映 | パック「サンドボックス素材」を作り、`sandbox-pack.zip` を投稿し、承認して zip に反映する |
| 投稿のプレビュー | 承認の前に、投稿の頁で顔・ユニットの絵、効果音を確かめる。「データビューアで見る・聞く」で MIDI も鳴らす |
| シナリオの投稿 | `sandbox-scenario.zip` を投稿し、一緒に使う共有パックで「サンドボックス素材」を選ぶ |
| SRC#Web で遊ぶ | パイロットの顔・ユニットの絵・BGM・効果音はシナリオに入っておらず、パックから読み込む。敵を 1 体倒すとインターミッションに進み、「次のステージへ」で終わる |
| インターミッション | セーブ・ユニットとパイロットの確認・機体改造と、追加したコマンド「サンドボックスについて」（生成AIで作ったテスト用であることの説明）。BGM は `sandbox_support.mid` |
| BGM | 始めると `sandbox_title.mid`。戦闘ではパイロットの BGM（`sandbox_battle.mid`）・ユニットの「ＢＧＭ」（`sandbox_support.mid`）・敵（`sandbox_enemy.mid`） |
| データビューア | シナリオの頁の「データビューアで見る」。データの BGM のボタンで曲を鳴らし、ほかの画面へ移っても鳴り続けること。パックの、データから使っていない絵（`Bitmap/Event/Sandbox_Unused.bmp`）と音（`Sound/sandbox_unused.wav`）が見られること |
| パックの更新 | パックに投稿を足して zip に反映し直し、SRC#Web で遊び直すと新しい版を取り直すこと |

`srcsharp play`（7474/SRC の SRCSharpTools）で、画面なしで最後まで動くことを確かめている。

```sh
# app に SRC# の最小の汎用データ（SRC.Sharp/Content/basic-data）と sandbox-pack.zip の中身を、sc に sandbox-scenario.zip の中身を置いて
srcsharp play sc/サンドボックス/サンドボックス.eve --script sandbox.play --app-path app --skip-wait
```

`sandbox.play` の中身:

```
# インターミッション：「サンドボックスについて」を開いてから「次のステージへ」
chooseseq コマンド サンドボックスについて|次のステージへ
auto 60
turns 10
expect message 動作確認は以上です
expect finished
expect error none
```

## サイトに入れる（本番）

運営のアカウントで、次の順に行う。

1. `/my/packs/new` でパックを作る
   - ID: `sandbox-assets`
   - 名前・説明・管理ポリシー: 下の「サイトに入れる文」
   - 投稿: 「管理者だけが投稿する」
2. パックの頁の「このパックに投稿する」から `sandbox-pack.zip` を上げる
3. `/my` の「パックへの投稿」から投稿を開き、中身を見て「承認して zip に反映する」。管理の頁で反映が終わるのを待つ
4. `/my/scenarios/new` でシナリオを作る（ID `sandbox`、文は下）。次の画面で `sandbox-scenario.zip` を上げる
5. 同じ画面の「一緒に使う共有パック」で「サンドボックス素材」に印を付けて保存する

手元の `wrangler dev`（`DEV_LOGIN=1`）では、`node scripts/register-sandbox.mjs` が 1〜5 をまとめて行う。
