# サンドボックス（生成AIで作ったテスト用のシナリオです）

> **このシナリオは、SRC#Site の動作確認のために生成AI（Claude）で作ったテスト用のものです。**
> 文章・データ・マップと、一緒に使う共有パック「サンドボックス素材」の画像・音楽・効果音は、すべて生成AIがプログラムで作りました。
> 作品として遊ぶためのものではありません。

## 確かめられること

| 項目 | 確かめ方 |
|---|---|
| SRC#Web で遊ぶ | シナリオの頁の「SRC#Web で遊ぶ」から始め、敵を倒すと終わる |
| 共有パックを重ねる | パイロットの顔・ユニットの絵・BGM・効果音は、このシナリオには入っておらず、共有パック「サンドボックス素材」（`sandbox-assets`）から読み込む |
| BGM | 始めると `sandbox_title.mid`、戦闘ではパイロットの BGM（`sandbox_battle.mid`）とユニットの「ＢＧＭ」（`sandbox_support.mid`）が鳴る。MIDI は SoundFont のパックで鳴らす |
| 効果音 | 会話の途中で `sandbox_beep.wav` が鳴る |
| データビューア | シナリオの頁の「データビューアで見る」で、データ・画像・音を見る。パイロットとユニットの BGM のボタンで曲を鳴らせる。共有パックの、データから使っていない画像・音（`Sandbox_Unused.bmp`・`sandbox_unused.wav`）も見られる |

## 入っているもの

- `サンドボックス.eve`: 最初に実行するイベント
- `sandbox.map`: 12×10 のマップ
- `Data/サンドボックス/`: パイロット・ユニットのデータ
