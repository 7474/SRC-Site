# SRC-Site

https://src.koudenpa.net

SRC（Simulation RPG Construction）のシナリオを投稿・配布するサイトです。投稿されたシナリオは、ブラウザ版の SRC#Web ですぐに遊べます。zip をダウンロードして、手元の SRC・SRC# で遊ぶこともできます。

## 遊ぶ

1. [トップ](https://src.koudenpa.net)の一覧か検索でシナリオを選びます
2. シナリオの頁の「SRC#Web で遊ぶ」を押します。インストールは要りません
   - セーブデータはブラウザに残ります。SRC#Web の画面から書き出し・読み込みもできます
   - シナリオに同梱された説明書（README など）は、SRC#Web の「文書」から読めます
3. 手元で遊ぶときは「ダウンロード」で zip を取得します

### 汎用データと BGM

汎用グラフィック集・汎用戦闘アニメ・効果音などの汎用データ（[共有パック](https://src.koudenpa.net/packs)）は、サイトが用意してシナリオと一緒に読み込みます。シナリオに入れなくても使えます。

BGM（版権曲など）はサイトでは配っていません。お持ちの MIDI・MP3 を zip にして、SRC#Web の「アーカイブを追加」の素材の欄から入れると、どのシナリオでも使えます。共有パックに同じ名前のファイルがあれば、入れたものが使われます。

## 投稿する

1. 右上の「ログイン」から Google のアカウントでログインします（サイトが受け取るのは Google の利用者 ID だけで、メールアドレスや氏名は受け取りません）
2. [設定](https://src.koudenpa.net/my)で表示名を決め、[利用規約](https://src.koudenpa.net/about/terms)に同意します
3. 「投稿」から、シナリオの ID（URL に使う英小文字・数字・`-`）・題名・説明・ライセンスなどを登録します
4. 次の画面で、シナリオのフォルダを zip にしたものを上げます。検査の後、すぐに公開されます（運営の確認はありません）
5. 必要なら、一緒に使う共有パックや、最初に実行する .eve を直します

### zip の決まり

| 項目 | 決まり |
|---|---|
| 中身 | シナリオ（.eve）が 1 つ以上あること。フォルダごと zip にしてかまいません |
| 大きさ | zip は 1 GB まで、展開後は 3 GB まで、ファイルは 50,000 個まで |
| 置けないもの | 実行ファイル（.exe・.dll・.bat など）、暗号化したファイル |
| ファイル名 | Windows（Shift_JIS）・macOS・Linux（UTF-8）のどちらで作った zip でも読めます |
| 投稿の量 | 1 人 1 日 10 版まで、合計 5 GB まで |

- 汎用データ（共有パックにあるもの）は zip に入れなくてかまいません
- 作品に使った素材の出典と条件は、「ライセンス・配布の条件」に書いてください
- 公開は「公開」「限定公開（一覧に出さず、URL を知っている人だけ遊べる）」「非公開」から選べます

## 素材を投稿する

画像・効果音・BGM・データなどの素材を、[共有パック](https://src.koudenpa.net/packs)に投稿できます。

1. ログインして「素材を投稿する」から、投稿先のパックを選びます。パックごとに管理ポリシー（自由・作者表記・個別の条件）が決まっています
2. 次の画面で、素材を SRC のフォルダの形（`Bitmap/Pilot/…`・`Sound/…`・`Midi/…`・`Data/…`）にした zip を上げます
3. シナリオの投稿者がそのパックを選ぶと、SRC#Web でシナリオと一緒に読み込まれます。同じ名前のファイルは、先に投稿された素材のものが使われます

- JASRAC の管理曲は投稿できません
- 投稿した素材・シナリオ・パックの中身（データ・画像・音）は、[データビューア](https://src.koudenpa.net/viewer/archives)で見たり聞いたりできます

## 規約と通報

- [利用規約](https://src.koudenpa.net/about/terms): 投稿した内容の責任は投稿者にあります。成人向けのシナリオは投稿できません。SRC 派生ソフトウェアの規約に従い、許諾の無い素材などは添付できません
- [権利者の方へ](https://src.koudenpa.net/about/rights): ご自身の作品・素材が許諾なく使われている場合や、問題のあるシナリオは、シナリオの頁の「このシナリオを通報する」からお知らせください
